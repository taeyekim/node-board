# MCP and External Tools Guide

## 목적

MCP와 외부 도구는 저장소 작업을 보조하기 위해 사용한다.
도구 사용 결과는 실제 확인한 범위만 보고한다.

## 사용 원칙

- 외부 문서가 필요한 경우 공식 문서를 우선한다.
- 최신 정보가 필요한 내용은 확인 후 출처를 남긴다.
- 사용자 승인 없이 외부 서비스 설정, 배포, 인증 연결을 변경하지 않는다.
- MCP 도구 결과를 과장하지 않는다.
- 확인하지 못한 내용은 미확인으로 기록한다.

## Tailwind CSS 참고 기준

Tailwind CSS는 무료 공식 문서와 예시를 기준으로 참고한다.
Tailwind UI 같은 유료 컴포넌트는 사용자 승인 없이는 사용하지 않는다.

## 배포 도구 기준

AWS EC2는 현재 범위에서 제외한다.
초기 배포는 Vercel과 Render를 우선 사용한다.

배포 도구를 사용할 때는 다음을 먼저 확인한다.

- 무료/유료 여부
- 필요한 계정 또는 인증
- 환경변수 설정 방식
- 빌드 명령
- 시작 명령
- 로그 확인 방법

사용자 승인 없이 배포 설정을 만들거나 변경하지 않는다.

## PostgreSQL 기준

PostgreSQL 설치, DB 생성, 스키마 변경, 배포 DB 연결은 사용자 승인 후 진행한다.
DB 접속 정보는 코드나 문서에 실제 값으로 기록하지 않는다.

## Redis/Nginx 기준

Redis와 Nginx는 로컬 인프라 연습용으로 Docker Compose를 우선 사용한다.
Redis는 optional cache로 구현하며, Redis 장애가 게시판 CRUD 자체를 막지 않아야 한다.
Nginx는 Vercel/Render 배포 필수 구성으로 보지 않고 reverse proxy 학습용으로 둔다.

## Swagger 기준

Swagger UI는 API 명세 확인과 수동 테스트용이다.
자동 테스트를 대체하지 않으며, 기능 완료 판정은 테스트/빌드/런타임/사용자 흐름 검증을 따로 기록한다.
