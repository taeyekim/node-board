# Security Rules

## 민감정보

다음 값은 코드나 문서에 직접 넣지 않는다.

- API Key
- 비밀번호
- 토큰
- 세션 시크릿
- DB 접속 문자열
- 개인 계정 정보

필요한 경우 `.env.example`에는 이름과 설명만 기록한다.

## 인증과 권한

인증, 권한, 세션, 쿠키 설정은 사용자 승인 없이 추가하거나 변경하지 않는다.

## API 변경

기존 API 응답 구조는 사용자 승인 없이 변경하지 않는다.
API 변경이 필요하면 영향 범위와 마이그레이션 필요 여부를 설명한다.

## 데이터 변경

DB 스키마, 마이그레이션, 배포 데이터는 사용자 승인 없이 변경하지 않는다.

## 의존성

패키지 설치, 삭제, 버전 변경은 사용자 승인 후 진행한다.
보안 취약점이 발견되어도 즉시 변경하지 말고 영향과 선택지를 먼저 보고한다.
